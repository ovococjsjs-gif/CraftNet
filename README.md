# CraftNet

**Смартфон в Minecraft.** Онлайн-магазин с доставкой в ПВЗ, банк с банкнотами,
живая биржа акций, GPS-карта, сотовая связь 2G/3G/4G от вышек у деревень,
новые здания в деревнях (ПВЗ, банк, завод, кафе) и четыре рабочих места.

Fabric-мод для **Minecraft 1.21.11**.

---

## Сборка

Стек совпадает с официальным шаблоном Fabric для 1.21.11:
**Loom(remap) 1.17.19 + Gradle 9.5.1 + JDK 25** (целевой байткод — Java 21).

В репозитории намеренно нет `gradle-wrapper.jar` (см. `.gitignore`),
поэтому собирает либо системный Gradle (9.5+), либо IDE:

```bash
gradle build

# Либо просто откройте проект в IntelliJ IDEA — она подтянет всё сама.
```

Готовый мод появится в `build/libs/craftnet-1.0.0.jar`.

## Сборка в GitHub Actions (CI)

В репозитории лежит готовый шаблон **`ci/github-actions-build.yml`**.
Чтобы включить автосборку на каждый push — просто переложите его в
`.github/workflows/build.yml` (например, через веб-интерфейс GitHub:
*Add file → Create new file → `.github/workflows/build.yml` → вставить содержимое шаблона → Commit*).

После этого:
- каждый push собирает мод на Temurin 25 + Gradle 9.5.1;
- готовый jar скачивается во вкладке **Actions → (прогон) → Artifacts → craftnet-jar**;
- выжимка лога сборки автоматически публикуется комментарием к коммиту
  (это удобно, когда полные логи рана скачать нельзя).

Запуск игры из репозитория (отладочный клиент):

```bash
gradle runClient
```

## Готовая сборка из CI

GitHub Actions собирает мод на каждый push: вкладка **Actions** →
зелёный прогон → внизу **Artifacts → craftnet-jar** → скачанный zip
содержит `craftnet-1.0.0.jar`.

2. **Fabric API 0.141.6+1.21.11** (или новее) в папку `mods`.

## Игровой процесс

### Смартфон
Выдаётся при первом заходе вместе со стартовым капиталом **100 CR**
(также крафтится: железо + стекло + редстоун + медь). Открытие — **ПКМ в руке**
или клавиша **P**.

Приложения:

- **Магазин** — купить почти любой предмет игры. Цена продажи всегда ниже
  цены покупки (72%). Купленное приезжает в **ПВЗ ближайшей деревни** —
  чем лучше связь, тем быстрее. Требуется **2G**.
- **Биржа** — 5 компаний (REDR, ENDT, CRPR, VLBK, NFSH), цена меняется каждые
  30 секунд, спред 2%, график-спарклайн. Требуется **3G**.
- **GPS** — карта как у миникарты (цвета блоков сверху), метки ближайших
  деревень с расстоянием. Работает только **на поверхности** (глубоко под
  землёй спутники не ловят).
- **Банк** — баланс и история операций, переводы онлайн-игрокам (**2G**).

### Связь 2G/3G/4G
Сигнал зависит от расстояния до **ближайшей деревни с рабочей вышкой**:
**4G** до 60 м, **3G** до 160 м, **2G** до 320 м, дальше — нет сети.
Команда `/craftnet signal` покажет текущий уровень.

**Вышка связи** строится автоматически *рядом* с деревней (не внутри) при
первом обнаружении. Сломаешь **ядро вышки** — деревня теряет сеть
(сигнал вернётся, если поставить новое ядро рядом). Ядро крафтится,
можно поставить свою антенну где угодно.

### Новые здания в деревнях
В обычных (и зомби-) деревнях всех видов теперь генерируются:

- **ПВЗ** — стойка + сотрудник (скин странствующего торговца). Здесь забирают
  покупки из магазина и отправляют товары на продажу (деньги капают с задержкой).
  Сюда же нанимаются **грузчиком**.
- **Банк** — терминал + банкир (библиотекарь). Обмен кредитов на **банкноты**
  (1–1000 CR) и обратно.
- **Завод** — бригадир (оружейник) даёт заказы на сборку редстоун-деталей.
- **Кафе** — бариста (мясник) даёт заказы на готовку и доставку еды.

Все станции активируются ПКМ по блоку стойки или по сотруднику.

### Работы (по убыванию оплаты)
1. **Завод** (×1.6) — собрать заказ редстоун-компонентов и сдать бригадиру.
2. **Грузчик** (×1.35) — отнести тяжёлый грузовой ящик жителю текущей деревни.
   Ящик **давит на спину** (Замедление II), цель подсвечена.
3. **Повар в кафе** (×1.15) — приготовить блюда и сдать баристе.
4. **Курьер** (×1.0) — разнести пакет еды жителю; чем больше порций в заказе
   (случайно 3–8), тем выше оплата. Без тяжести.

Одно задание за раз, срок — 10 минут. Подделать задание нельзя:
сервер пересоздаёт его детерминированно.

### Админ-команды (op)
```
/craftnet money add <игрок> <N>   /craftnet money set <игрок> <N>
/craftnet village rescan|list   /craftnet tower spawn
/craftnet job cancel <игрок>    /craftnet stocktick
```

## Структура кода

```
net.craftnet
├─ CraftNet / CraftNetClient      точки входа
├─ item/        телефон, банкнота (компонент номинала)
├─ block/       стойки ПВЗ/банка/завода/кафе, ядро вышки, грузовой ящик
├─ component/   DataComponent «номинал банкноты»
├─ state/       PersistentState: деньги, биржа, заказы, деревни, задания
├─ econ/        MoneyManager, PriceManager (~150 цен + эвристика), StocksManager
├─ orders/      заказы магазина (доставка в ПВЗ, отложенные выплаты)
├─ jobs/        4 работы, детерминированные офферы, тяжесть грузчика
├─ village/     реестр деревень, вышки, уровни связи, инжектор зданий в пулы
├─ network/     3 пакета (open/sync/action) + вся серверная логика экранов
├─ client/gui/  телефон/ПВЗ/банк/работы, UiKit (панели/кнопки/инпуты)
├─ client/      GPS-рендер в динамическую NativeImage-текстуру
└─ mixin/       доступ к полям StructurePool
tools/
├─ gen_textures.py    генерация 16×16 PNG-текстур (чистый Python)
└─ gen_structures.py  генерация NBT-структур зданий (gzip NBT, DataVersion 4671)
```

Детали дизайна и проверенные факты API — в [DESIGN.md](DESIGN.md).

> Примечание: текстура банкноты — временная процедурная заглушка,
> финальный рисунок банкноты будет предоставлен отдельно
> (файл `assets/craftnet/textures/item/banknote.png`, 16×16).
