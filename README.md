# CraftNet

**Смартфон в Minecraft.** Онлайн-магазин с доставкой в ПВЗ, банк с банкнотами,
живая биржа акций, GPS-карта, сотовая связь 2G/3G/4G от вышек у деревень
(вышки прокачиваются!), новые здания в деревнях (ПВЗ, банк, завод, кафе),
четыре рабочих места и личный профиль с достижениями.

Fabric-мод для **Minecraft 1.21.11**.

---

## Сборка

Стек совпадает с официальным шаблоном Fabric для 1.21.11:
**Loom(remap) 1.17.19 + Gradle 9.5.1 + JDK 25** (целевой байткод — Java 21).

В репозитории намеренно нет `gradle-wrapper.jar` (см. `.gitignore`),
поэтому собирает либо системный Gradle (9.5+), либо IDE:

```bash
gradle build

# Либо просто откройте проект в IntelliJ IDEA — она подтянет всё сама.
```

Готовый мод появится в `build/libs/craftnet-1.0.0.jar`.

## Сборка в GitHub Actions (CI)

В репозитории лежит готовый шаблон **`ci/github-actions-build.yml`**.
Чтобы включить автосборку на каждый push — просто переложите его в
`.github/workflows/build.yml` (например, через веб-интерфейс GitHub:
*Add file → Create new file → `.github/workflows/build.yml` → вставить содержимое шаблона → Commit*).

После этого:
- каждый push собирает мод на Temurin 25 + Gradle 9.5.1;
- готовый jar скачивается во вкладке **Actions → (прогон) → Artifacts → craftnet-jar**;
- выжимка лога сборки автоматически публикуется комментарием к коммиту
  (это удобно, когда полные логи рана скачать нельзя).

Запуск игры из репозитория (отладочный клиент):

```bash
gradle runClient
```

## Готовая сборка из CI

GitHub Actions собирает мод на каждый push: вкладка **Actions** →
зелёный прогон → внизу **Artifacts → craftnet-jar** → скачанный zip
содержит `craftnet-1.0.0.jar`.

## Установка в игру

1. Fabric Loader **0.19.3+** для Minecraft **1.21.11**.
2. **Fabric API 0.141.6+1.21.11** (или новее) в папку `mods`.
3. `craftnet-1.0.0.jar` туда же.

## Игровой процесс

### Смартфон
Выдаётся при первом заходе вместе со стартовым капиталом **100 CR**
(также крафтится: железо + стекло + редстоун + медь). Открытие — **ПКМ в руке**
или клавиша **P**. Смартфон должен быть в инвентаре — без него интерфейс
не откроется (потерял — крафти новый).

Приложения (домашний экран — плитки, статус-бар со временем, сетью,
батареей и балансом, звуки кликов):

- **Магазин** — купить почти любой ВАНИЛЬНЫЙ предмет (посторонние моды в
  каталог не попадают): поиск, выбор количества, кнопка показывает итоговую
  сумму. Цена продажи всегда ниже цены покупки (72%). Купленное приезжает
  в **ПВЗ ближайшей деревни** — базово **2 минуты** на 4G, чем хуже связь,
  тем дольше (3G ×2, 2G ×3). Требуется **2G**.
- **Барахолка** — маркетплейс игроков: в ПВЗ любой предмет выставляется
  кнопкой **₽** по своей цене (до 6 лотов, живут 3 игровых дня, снятие и
  истечение — возврат почтой). Покупка из телефона приезжает в твой ПВЗ,
  продавцу — выплата минус **комиссия 5%**. Требуется **2G**.
- **Апгрейд** — интернет-казино с циферблатом, теперь в **три шага**:
  **1.** ставка — кликай предметы из сетки инвентаря (Shift = ×8), вспышка
  подтверждает приём; **2.** цель — поиск/листай каталог или жми **пресет**
  (алмаз / незерит / алмазный меч); **3.** пульсирующая «КРУТИТЬ!». Если
  кнопка не активна — на ней же написано, чего не хватает. Дуга шанса
  плавно перетекает при смене ставки/цели. Шанс честный:
  **стоимость ставки / стоимость приза** (приз вдвое дороже → ровно 50%),
  ограничение 1–95%. Чипы **x2/x4/x8/30%/50%/70%** добирают ставку до
  порога автоматически. Стрелка делает несколько оборотов и останавливается
  внутри оранжевой дуги при победе (дуга = твой шанс). Исход решает сервер.
  Выигрыши с шансом ≤20% летят в общий чат. Требуется **2G**.
- **Биржа** — 5 компаний с собственными характерами и коридорами цен
  (спокойный VLBK 140–230 с жирными дивидендами, дикая CRPR 35–150 и т.д.).
  Цены **дышат постоянно** — пульс каждые ~5 секунд, плюс редкие спайки
  ±3–9% и новости с шоком ±6–20% каждые 2–4 минуты. Спред 2%, **дивиденды**
  каждые игровые сутки держателям (все выплаты логируются в консоль сервера).
  Требуется **3G** (или **2G** под «умной вышкой» ур.4).
- **GPS** — живая миникарта, которая едет за тобой: зум **1/2/4** блока на
  пиксель, стрелка направления взгляда, метки деревень (зелёные онлайн,
  красные сломанные) со списком ближайших, **маршрутная метка по клику**
  с дистанцией, оранжевая метка **цели активной работы**. Работает только
  **на поверхности** (глубоко под землёй спутники не ловят).
- **Банк** — баланс и история операций, **переводы онлайн-игрокам** прямо
  из телефона (имя + сумма, **2G**), **ежедневный процент** на остаток
  (0.15%, до 25 CR в сутки). Обналичивание — в банкомате у банкира.
- **Профиль** — твоя статистика по всем экономикам (смены, зарплата,
  продажи, биржа, казино, вложения в вышки), **опыт и уровни со званиями**
  (Новичок → Легенда) и **12 достижений** с прогрессом — от «Первой смены»
  до «Миллионера».

### Связь 2G/3G/4G
Сигнал зависит от расстояния до **ближайшей деревни с рабочей вышкой**:
**4G** до 120 м, **3G** до 320 м, **2G** до 640 м, дальше — нет сети. Покрытие расширено вдвое.
Команда `/craftnet signal` покажет текущий уровень.

**Вышка связи** ставится **мгновенно**: как только подгружается чанк с
центром деревни (событие загрузки чанков, без периодических сканов),
вышка появляется *рядом* с деревней — подойдёшь к новой деревне, а она
уже стоит. Сломаешь **ядро вышки** — деревня теряет сеть
(сигнал вернётся, если поставить новое ядро рядом). Ядро крафтится,
можно поставить свою антенну где угодно.

**Апгрейды вышки (ПКМ по ядру, оплата со счёта):** 4 уровня улучшений —
радиусы растут до **330/880/1760 м** (ур.4), с ур.3 доставка заказов
ускоряется на целый тир, а **ур.4 «Умная вышка»** даёт всем абонентам
биржу уже в **2G** и **скидку 5% в магазине**. Мачта визуально растёт
с каждым уровнем (появляются антенны и лампы), на GPS-карте видно кольца
покрытия 4G. Прокачка — общественная: работает для всех игроков сервера.

### Новые здания в деревнях
В обычных (и зомби-) деревнях всех видов мод **сразу достраивает** четыре
фирменных здания из блоков CraftNet: как только игра видит центр деревни,
вокруг неё на ровных площадках размещаются готовые постройки (NBT-шаблоны)
**вместе с NPC внутри** — без «пустых коробок» и без ожидания сканирования.
Недостроенное из-за незагруженных чанков мод не бросает: до ~30 попыток
достройки с интервалом. Плюс здания инжектятся в пулы генерации — новые
деревни могут рождаться уже с нашими постройками в улицах.

- **ПВЗ** — стойка + сотрудник (скин странствующего торговца). Посылки
  показывают **прогресс доставки** и таймер, списки листаются страницами
  **или колесом мыши**, есть «забрать всё». Здесь же продают товары из
  инвентаря — **всё сразу или частью** (поле «шт»), деньги капают
  с задержкой — честная **лента ожидаемых выплат** показывает сумму, ETA
  и прогресс каждой выплаты. Лот на барахолку выставляется кнопкой ₽
  (штучно или всё количество — из того же поля). Здесь же нанимаются
  **грузчиком** и отменяется любая текущая смена.
- **Банк** — терминал + банкир (библиотекарь). Обмен кредитов на **банкноты**
  (1–1000 CR) и обратно.
- **Завод** — бригадир (оружейник) даёт заказы на сборку редстоун-деталей.
- **Кафе** — бариста (мясник) даёт заказы на готовку и доставку еды.

Все станции активируются ПКМ по блоку стойки или по сотруднику.

Прибытие покупки в ПВЗ сопровождается сообщением в чат и звуком, а в HUD
(правый нижний угол) всегда видны сигнал сети, ближайшая деревня, статус GPS
и баланс — при его изменении всплывает **«+N CR / −N CR»**. Домашний экран
телефона показывает **баннер входящих**: сколько посылок едет и какая сумма
выплат в пути, с ETA. Полный гайд прямо в игре: **`/craftnet tutorial`**.

### Работы (по убыванию оплаты, диапазоны не пересекаются)
1. **Завод** (195–285 за смену) — на выбор: мини-игра «сборка по схеме»
   (повторяй порядок деталей кликами, три ошибки — брак) ИЛИ **цеховой
   крафт-заказ**: склад выдаёт помеченные (◆) материалы, собираешь детали
   на верстаке и сдаёшь бригадиру.
2. **Грузчик** (150–190, зависит от дальности) — тяжёлый ящик жителю;
   ящик **давит на спину** (Замедление II), цель светится + стрелка-навигатор.
3. **Повар в кафе** (110–145) — крафт-заказ кухни: бариста выдаёт помеченные
   продукты, готовишь блюда и сдаёшь баристе. Повар ≠ курьер: разнос ушёл
   курьеру полностью.
4. **Курьер** (25–50) — доставка пакетов еды жителю (3–8 порций),
   цель светится + навигатор.

Одно задание за раз, срок 10 минут (крафт-заказы — 15). **Срыв смены —
штраф**: отмена 25% / таймаут 30% от оплаты + оценка потерянных помеченных
материалов и конфискация груза. Подделать задание нельзя: сервер пересоздаёт
его детерминированно.

### Настройки сервера
Все экономические и логистические константы вынесены в
**`config/craftnet.json`** (создаётся при первом запуске, недостающие ключи
дописываются сами): стартовый капитал, время доставки и TTL посылок,
комиссия/сроки барахолки, неустойки за срыв смен, банковский процент/потолок,
лимиты казино-апгрейдера, скидка «умной вышки», период синхронизации экранов.
Градации и пределы защищены от некорректных значений (санитизация при загрузке).

### Команды
Для всех: `/craftnet signal`, `/craftnet tutorial`, `/craftnet job cancel`
(отмена СВОЕЙ смены — со штрафом; то же умеет кнопка на экране ПВЗ).
Админские (op):
```
/craftnet money add <игрок> <N>   /craftnet money set <игрок> <N>
/craftnet village rescan|list   /craftnet tower spawn
/craftnet job cancel <игрок>    /craftnet stocktick
```

## Структура кода

```
net.craftnet
├─ CraftNet / CraftNetClient      точки входа
├─ item/        телефон, банкнота (компонент номинала)
├─ block/       стойки ПВЗ/банка/завода/кафе, ядро вышки, грузовой ящик
├─ component/   DataComponent «номинал банкноты» + тег рабочего имущества
├─ state/       PersistentState: деньги, биржа, заказы, деревни, задания, профили
├─ econ/        MoneyManager, PriceManager (~170 цен + эвристика), StocksManager
├─ stats/       профиль игрока: счётчики, опыт/уровни, 12 достижений
├─ orders/      заказы магазина (доставка в ПВЗ, отложенные выплаты)
├─ jobs/        4 работы, детерминированные офферы, тяжесть грузчика
├─ village/     реестр деревень, вышки + их апгрейды, инжектор зданий в пулы
├─ network/     3 пакета (open/sync/action) + вся серверная логика экранов
├─ client/gui/  телефон (8 вкладок)/ПВЗ/банк/работы/вышка, UiKit
├─ client/      GPS-рендер в динамическую NativeImage-текстуру
└─ mixin/       доступ к полям StructurePool
tools/
├─ gen_textures.py    генерация 16×16 PNG-текстур (чистый Python)
└─ gen_structures.py  генерация NBT-структур зданий (gzip NBT, DataVersion 4671)
```

Детали дизайна и проверенные факты API — в [DESIGN.md](DESIGN.md).

> Примечание: текстура банкноты — временная процедурная заглушка,
> финальный рисунок банкноты будет предоставлен отдельно
> (файл `assets/craftnet/textures/item/banknote.png`, 16×16).
